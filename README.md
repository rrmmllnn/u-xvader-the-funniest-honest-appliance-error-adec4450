## The line

> Error UE: spin cancelled. One towel, one sock, and a duvet like a wet brick. I refuse to shake myself apart.

A washing machine, flat and put-upon, refusing to spin an unbalanced
load. The fault is real (UE is the unbalanced-load code; a heavy wet
duvet unbalances the drum, so the machine cancels the spin), the load
is concrete and counted, and the joke is the refusal itself — the
machine will not shake itself apart for one towel, one sock and a
duvet like a wet brick.

## How it works

`main.py` is the packed entrypoint (built with `makefun compress` from
the readable source `line_src.py`). Running it writes exactly that
one line — 108 characters, no trailing newline — to
`/output/entry.txt`, deterministically, with no network and no input.
